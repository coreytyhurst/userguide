# Frequently Asked Questions

Click any question to see the answer.

{{% details "How do I get an account?" %}}
Email Corey at [coreytyhurst@gmail.com](mailto:coreytyhurst@gmail.com). He'll set you up with credentials for the apps you need access to.
{{% /details %}}

{{% details "Do I need a separate login for each app?" %}}
No -- almost everything uses the same username and password:

- **TV & Movies, Audiobooks, Requesting Content, and Music** all use your Farmhouse login.
- **Radio** and **Retro Gaming** don't require a login at all.
- **D&D** is the only exception -- your DM gives you separate player credentials for it.

If the Music app rejects your login, you may not have been added to it yet -- email Corey.
{{% /details %}}

{{% details "Can I access this from outside the house?" %}}
Yes. Everything works over the internet from anywhere. Just use the same links in this guide.
{{% /details %}}

{{% details "Is there a mobile app?" %}}
Yes, for most services. Check each service's guide page for specific app recommendations and setup instructions.
{{% /details %}}

{{% details "Can I share my account with someone else?" %}}
Please don't. If someone else wants access, have them reach out to Corey for their own account. Shared accounts cause playback conflicts (like one person's watching interrupting another's).
{{% /details %}}

{{% details "How do I change my password?" %}}
You can change it in the app's own settings. If you're having trouble, email Corey to reset it.

- **TV & Movies (Jellyfin):** click your user icon (top right) -> **Settings** -> **Password**.
- **Music (Navidrome):** click your username (bottom left) -> **Personal Settings** -> **Password**.
{{% /details %}}

{{% details "Why is something buffering or slow?" %}}
See [Troubleshooting]({{< relref "/docs/troubleshooting" >}}) for common fixes. Most of the time, it's a browser or network issue on your end rather than a server problem.
{{% /details %}}

{{% details "How do I request a movie or TV show?" %}}
Use the [request app]({{< relref "/docs/requesting-content" >}}). It's separate from the streaming app.
{{% /details %}}

{{% details "Why am I asked for a code sent to my email?" %}}
Most apps show a Cloudflare security screen before their own login. Enter the email address linked to your account, click **Send Code**, and check your inbox for a 6-digit code. This appears the first time on each device. See [Your first login]({{< relref "/docs/getting-started#your-first-login" >}}) for details. If the email doesn't arrive, check your spam folder.
{{% /details %}}

{{% details "The site says my connection isn't secure." %}}
This shouldn't happen. If you see a security warning, make sure you're using the correct URL from this guide. If it persists, let Corey know.
{{% /details %}}
