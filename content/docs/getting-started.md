# Getting Started

Welcome! The Farmhouse server hosts a bunch of apps for watching movies, listening to music, playing games, and more. Everything runs from our home server and is available to family and friends.

## What you need

- **An account.** You should have received a username and password from Corey. If you haven't, email him at [coreytyhurst@gmail.com](mailto:coreytyhurst@gmail.com).
- **A device.** Any phone, tablet, computer, or smart TV will work for most apps.
- **An internet connection.** Everything works over the internet, whether you're at the farmhouse or anywhere else.

## Quick start

1. **Go to the dashboard** at [home.tyhurstfarmhouse.com](https://home.tyhurstfarmhouse.com) -- a single page with links to every Farmhouse app. Not everything listed there has a guide page; if you don't recognize something, you probably don't need it.
2. **Pick an app** from the dashboard or from this guide.
3. **Log in** with the username and password you were given.

> Almost every app uses the same username and password. D&D is the exception -- your DM gives you separate player credentials for it.

## Your first login

The first time you open an app on a new device or browser, you'll see a **Cloudflare security screen** before the app's own login page. This is a normal extra security step -- not an error.

1. Enter the **email address** linked to your account.
2. Click **Send Code**. A 6-digit code arrives by email within a minute.
3. Enter the code to continue to the app.

You won't do this every time -- only on a new device, or if it's been a while. If the code doesn't arrive, check your spam folder.

## Tips

- **Use Chrome or Edge** for the best experience on a computer. Safari works but occasionally has quirks.
- **Bookmark the dashboard** so you can always find your way back.
- **Check this guide first** if something isn't working. The [Troubleshooting]({{< relref "/docs/troubleshooting" >}}) page covers the most common fixes. Still stuck? The best way to reach Corey is email: [coreytyhurst@gmail.com](mailto:coreytyhurst@gmail.com).
