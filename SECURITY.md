# Security

This repository is the source for a **static documentation website**. It contains no
application code, no server logic, and no secrets or credentials.

## Reporting a problem with the guide

If a page is inaccurate or a link is broken,
[open an issue](https://github.com/coreytyhurst/userguide/issues/new/choose). This is not
sensitive — a public issue is fine.

## Farm-cluster server or account security

If your concern is about the **Farmhouse server itself** — a suspected account compromise,
a login that isn't working as expected, or anything that feels unsafe — **do not open a
public issue.** Contact the admin privately:

**coreytyhurst@gmail.com**

Please include enough detail to understand and reproduce the concern.
